# Spider-Verse Video Style — ComfyUI

Apply a Spider-Verse-inspired comic-book style to video using **FLUX.2 Klein 4B**, with prompts generated by **gpt-oss-120b through Groq's free API tier**. ComfyUI runs on **RunPod**.

**Groq is the inference platform; gpt-oss-120b is the LLM.** Groq free-tier limits apply, and RunPod hosting is paid separately.

## Workflow

Import [spider-verse-groq.json](spider-verse-groq.json) into ComfyUI. **The API-key field is blank.** Enter your own key locally in Groq Chat before running; remove it again before sharing an export.

Video → select every Nth frame → generate prompts through Groq → style frames with FLUX → save MP4 with original audio.

## Required node repositories

- [KJNodes](https://github.com/kijai/ComfyUI-KJNodes) — text prompts and frame interval.
- [ComfyUI Timesaver](https://github.com/AlexYez/comfyui-timesaver) — split frames into a list and collect edited frames.
- [VideoHelperSuite](https://github.com/Kosinkadink/ComfyUI-VideoHelperSuite) — select every Nth frame.
- [EACloudNodes](https://github.com/EnragedAntelope/ComfyUI-EACloudNodes) — Groq Chat API connection.
- [Fill Nodes](https://github.com/filliptm/ComfyUI_Fill-Nodes) — turn generated text into a prompt list.

The model loaders, FLUX editing, regex, FPS calculation, and video export use ComfyUI core nodes.

## Models

Download the models from the [official FLUX.2 Klein guide](https://docs.comfy.org/tutorials/flux/flux-2-klein):

- `models/diffusion_models/flux-2-klein-4b-fp8.safetensors`
- `models/text_encoders/qwen_3_4b.safetensors`
- `models/vae/flux2-vae.safetensors`

## Use it

1. Install the nodes and models on your RunPod ComfyUI instance, then restart.
2. Import the JSON, upload your video, select the models, and enter your own Groq key.
3. Set **Shared N (120)**. Default **4** keeps every fourth frame; output FPS is source FPS ÷ N. For example, 30 FPS becomes 7.5 FPS.
4. Check that Groq returns one prompt per selected frame, then inspect the result in `ComfyUI/output/video/`.

**To apply another style**, replace the text in **Style Treatment (84)**. The included preset uses comic outlines, halftones, cel shading, and cyan/magenta accents.

Frame-by-frame editing can flicker or alter details. Audio is connected and duration is approximately preserved; check the final synchronization. This packaged JSON passed structural checks but has not been runtime-tested during packaging.
